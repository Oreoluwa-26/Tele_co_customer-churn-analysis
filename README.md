Customer Churn Analysis & Prediction
Project Overview

Customer churn is a major challenge for subscription-based businesses. This project focuses on analyzing customer behavior and building machine learning models to predict customer churn using a telecom dataset.

Objectives

-Understand key drivers of customer churn

-Build predictive churn models

-Provide actionable business recommendations to reduce churn

Approach Used

-Problem framing and business understanding

-Data cleaning and preparation

-Exploratory Data Analysis (EDA)

-Feature engineering

-Churn modelling using Logistic Regression and Random Forest

-Model evaluation and postdictive analysis

-Business recommendations

 Models Used

-Logistic Regression (primary model)

-Random Forest (benchmark comparison)

 Key Results

-Logistic Regression achieved an ROC-AUC of ~0.84

-Threshold tuning improved recall for churners

-Key churn drivers included tenure, contract type, and monthly charges

 Business Insights

-New and month-to-month customers are at higher risk

-High-charge customers require targeted retention strategies

-Early intervention can significantly reduce churn
